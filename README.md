## 📌 Project Overview
The Calculator Project Using Streamlit is a Python-based web application designed to perform mathematical calculations through an interactive user interface.
The application uses the Streamlit framework to transform Python programming logic into a browser-based application. It demonstrates how Python can be integrated with Streamlit to develop interactive web applications without requiring traditional frontend technologies.

## ⚙️ Installation and Setup
Follow these instructions to configure and run the application locally.

### 1. Clone the Repository
bash
git clone https://github.com/alijamil14/Calculator-Project-Using-Streamlit.git

### 2. Navigate to the Project Directory
bash
cd Calculator-Project-Using-Streamlit

### 3. Create a Virtual Environment
bash
python -m venv .venv

Activate the environment on Windows:
bash
.venv\Scripts\activate


### 4. Install Dependencies
bash
pip install -r requirements.txt

Alternatively:
bash
pip install streamlit

### 5. Run the Application
bash
streamlit run calculator.py

### 6. Access the Application

Open the following address in your browser:
http://localhost:8501
